# viqueue v0.2.0

> Early prerelease for local evaluation. Not production-ready.

v0.2.0 is the first public-source release candidate for viqueue, a local pull-based ticket dispatcher for agents and humans.

## Included

- Durable local JSON storage and HTTP application API
- `viq` command-line client with stable JSON output and exit codes
- MCP stdio adapter using the same HTTP application contract
- Responsive human Kanban board with explicit stale/uncertain handling
- Claim renewal, explicit authorized takeover, monotonically increasing fencing generations, and evidence submission
- Deterministic local install/uninstall archive

## Important limitations

- Single server process and local JSON storage
- Local bearer takeover gate, not production authentication
- No worker launching, cloud deployment, or package-registry publication
- Trademark/name clearance is incomplete
- Pre-1.0 APIs may change with documentation
