# viqueue v0.5.3 prerelease

> Prerelease for controlled private evaluation; not production-ready.

v0.5.3 repairs a demonstrated native Pi 0.83 settlement race in the installed v0.5.2 adapter. An `agent_settled` ticket read could remain in flight while a successful blocker/terminal cleanup, release, completion, shutdown, or replacement session retired its claim. The old continuation then dereferenced cleared runtime state or acted on a replacement episode.

## Runtime fix

Each settlement read now captures the exact runtime observation epoch, claim object, and worker session before awaiting HTTP. Its continuation proceeds only while all three identities remain current. Resolved and rejected results from a retired observation return without dereferencing cleared state, heartbeating a replacement claim, or making a stale session-rotation decision.

A settlement transport failure that still belongs to the active episode is not swallowed: the native extension reports it through the existing visible Pi error notification path. Existing completion, release, blocking-question, shutdown, rotation, and fail-closed unknown-outcome behavior remains unchanged.

## Scope and validation

The deterministic regression suite drives the real worker runtime through actual extension/controller `agent_settled`, tool, shutdown, and replacement-session hooks. It holds the ticket GET at the demonstrated boundary and covers successful block-then-shutdown cleanup, explicit release, direct completion, shutdown, fresh post-terminal rotation, retired resolved and rejected requests, active rejected requests, and a same-ticket replacement claim. Fixture configuration isolates host credentials and all fixture transport is pinned to a non-routable fixture origin.

This patch adds no retry engine, durable supervisor state, scheduler, expiry/takeover behavior, automatic recovery, network retry loop, or watchdog. It does not change the product kernel or require a backend deployment.

This candidate does not tag, publish, upload, install, deploy, make a live request, mutate live Viq state, or claim production verification. Release authority and external artifact verification remain separate.
