# viqueue v0.4.1 prerelease

v0.4.1 is the bounded security successor to v0.4.0 for an approved phone gateway that must reach one exact Tailscale HTTPS upstream. It does not deploy or change any ingress, DNS, firewall, tailnet, pairing, or device state.

## Security contract

- The unchanged default accepts only fixed loopback HTTP upstreams.
- Remote HTTP is always denied.
- Remote HTTPS requires `--upstream-address-policy=tailscale` and one exact root-form DNS origin on canonical port 443.
- Every new connection freshly resolves the configured hostname and rejects empty, malformed, oversized, or mixed answer sets unless every address is within Tailscale `100.64.0.0/10` or `fd7a:115c:a1e0::/48`.
- The TLS socket connects to the already validated address while SNI, HTTP authority, standard CA validation, and hostname verification remain bound to the configured hostname.
- Native Node HTTPS ignores ambient proxy variables and does not follow redirects. Client authority, forwarding, credential, proof, and hop-by-hop headers remain stripped.
- DNS, TLS connection, whole-request, request-target, and request-body bounds fail closed.

The isolated `viq-trace-tailscale-upstream` launcher performs only read-only GET probes to the exact `https://cc-worker.twin-pogona.ts.net` origin.

This remains a prerelease. The release asset is an unsigned deterministic archive with a published SHA-256 checksum; no cryptographic signing or provenance attestation is claimed.
