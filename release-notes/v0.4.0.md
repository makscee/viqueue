# viqueue v0.4.0 — Human queue repair and single-phone gateway

> Prerelease for controlled evaluation and later staging handoff; not production-ready.

## Included

- Human-first desktop and mobile queue projections with clearer assignment and event facts.
- An isolated single-phone proof gateway with one-use pairing intents and challenges, a device-bound non-exportable browser key, local revocation, exact request signatures, and bounded loopback proxying.
- Fail-closed raw-target validation and stripping of credentials, forwarding headers, hop-by-hop headers, and upstream cookies.
- CLI and browser phone-auth flows plus full CLI, MCP, desktop/mobile browser, and phone E2E coverage.
- Deterministic local install archive containing `viq`, MCP/import tools, and phone-auth/gateway launchers.

## Security and deployment boundary

This release does not deploy or activate the gateway. Keep the application upstream on loopback/private transport. Follow the staging runbook and threat model before any later deployment. Do not expose the upstream application directly, enable Funnel, reuse pairing links, or treat workflow identity as general adversarial authentication.

One active paired phone is supported. Revocation is local and immediate. Pairing URLs, device credentials, private keys, certificates, hostnames, and production configuration are not release assets.

## Verification

Verify `viqueue-v0.4.0-rc.tar.gz` with the accompanying SHA-256 file before installation. `SOURCE_COMMIT` inside the archive identifies the exact canonical public source commit.
