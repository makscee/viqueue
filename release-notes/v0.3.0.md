# viqueue v0.3.0 — Daily Alpha core

> Unpublished prerelease for local evaluation; not production-ready.

- One SQLite file with transactional in-place migration for actors, roles, typed assignment, and questions.
- Durable fenced authority claims with explicit release, submission, or takeover only.
- Stable actors with machine metadata and multi-valued roles; active eligibility for actor/role assignments.
- Multiple non-blocking text questions plus actor/role inboxes; first answer wins atomically.
- Submit creates one explicitly targeted approval; accept/request_changes alone drives review lifecycle.
- Append-only global/per-ticket event cursor and progress observations.
- HTTP-backed CLI, MCP stdio adapter, and responsive Ready/Working/Review/Done board.
- Explicit fail-closed one-shot import from v0.2 JSON.

A claim persists until an explicit release, submission, or takeover. Silence changes nothing.

Progress events are observations, not proof of liveness.

Agents pull work; viqueue never starts workers. This repository change does not publish, push, tag, deploy, or mutate an external service.
